# متجر السندباد — نسخة مستقلة للنشر

هذه نسخة HTML/CSS/JavaScript مستقلة عن Claude وبدون React أو ملفات تشغيل خاصة.

## النشر على Vercel
1. سجّل الدخول إلى https://vercel.com
2. اختر Add New → Project.
3. ارفع هذا المجلد إلى مستودع GitHub (أو استورد المستودع).
4. في إعدادات المشروع اترك Framework Preset على Other.
5. اترك Build Command وOutput Directory فارغين أو اجعل Output Directory هو `.`.
6. اضغط Deploy.

الصفحة الرئيسية هي `index.html`، والصور داخل `assets/`.
